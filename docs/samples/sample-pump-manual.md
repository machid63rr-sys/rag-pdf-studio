# ポンプ（サンプル）取扱説明書

動作確認用の架空のサンプルです。実在の機器・マニュアルとは関係ありません。

## 日常の点検

運転中は、異音・異常な振動・軸受の温度に注意してください。軸封部からの水漏れが規定量を超えていないか確認してください。

## 不具合の原因と対策

| 不具合 | 原因 | 対策 |
|---|---|---|
| 異常な振動がある | 軸受の摩耗 | 軸受を交換する |
| 異常な振動がある | 芯出しの不良 | 芯出しをやり直す |
| 水が出ない | 吸込配管への空気の混入 | 呼び水をして、空気を抜く |
| 電流値が高い | 羽根車に異物が詰まっている | 運転を止めて、異物を取り除く |
| 軸封部から水が漏れる | グランドパッキンの摩耗 | パッキンを交換する |

## 長期間運転しない場合

ポンプ内の水を抜き、軸が固着しないよう、月に1回は手で軸を回してください。
